# 指尖分类 · 甬上洁净

一个用**手势**玩的垃圾分类小游戏。右手握拳抓起垃圾，移到对应的垃圾桶上方，张开手掌投放。
60 秒限时，分对得分、连击翻倍，分错扣 3 秒。视觉沿用「甬上四季」的宣纸／淡墨／朱砂。

---

## 一、怎么启动

> ⚠️ **不要直接双击 `index.html`**。摄像头在 `file://` 下会被浏览器拦截，必须通过本地服务访问。

### macOS：双击「启动.command」

1. 在项目文件夹里找到 **`启动.command`**，双击它。
2. 会弹出一个终端窗口，自动启动服务并用默认浏览器打开页面。
3. 页面加载后，点击 **「进 入」** 按钮 → 浏览器弹窗请求摄像头时点 **「允许」**。
4. **用完关闭那个终端窗口即可停止服务。**

> 首次双击可能被拦截：提示「无法打开，因为无法验证开发者」时，右键 `启动.command` → 选「打开」→ 再点「打开」即可。之后就不会再拦。

### Windows：双击「启动.bat」

同上。窗口里会打印地址（一般是 `http://localhost:8000`），浏览器会自动打开。
**不要关闭那个黑窗口**，关了服务就停了。

### 方式三（备选）：命令行

```bash
cd 项目所在目录
python3 -m http.server 8000     # Windows 上用 python -m http.server 8000
```

然后浏览器打开 **http://localhost:8000**。

如果提示 `Address already in use`，说明 8000 端口被占了，换个数字：

```bash
python3 -m http.server 8001
```

然后访问 `http://localhost:8001`。

## 二、怎么玩

| 操作 | 效果 |
| --- | --- |
| **右手握拳**（在画面前，离摄像头 30–60cm） | 抓住画面中间的垃圾，它跟着你的手走 |
| **把手移到某个桶上方** | 该桶的盖子会自动掀开、亮起朱砂细线 |
| **张开手掌** | 把垃圾投进这个桶 |
| 分对了 | +分、连击 +1、金色火花、桶盖弹开 |
| 分错了 | 扣 3 秒、连击清零，并提示「应投『某某垃圾』」 |
| 松手时没对准任何桶 | 垃圾自己飘回画面中间，不算错 |

- **限时 60 秒**，时间到自动结算，显示得分、正确 / 分错、准确率和最高连击，并写明计分规则。
- **开局引导**：每局开始时画面中央会浮出「握拳抓取 · 张开投放」，抓起第一件垃圾后自动隐去。
- **连击翻倍**：连续分对时每件垃圾的得分 = 10 × 连击数，最高 ×5；左上角连击数后会直接标出当前倍率（如「3 ×3」）。
- **历史最高分**会记在浏览器本地，下次打开还在。

### 键盘 / 鼠标降级（摄像头用不了时）

| 操作 | 效果 |
| --- | --- |
| 鼠标移动 / 按住拖动 | 移动光标、抓起垃圾 |
| `←` `→` `↑` `↓` | 移动光标 |
| `空格` | 抓取 / 投放 |

> 摄像头失败时游戏照常开始，会自动切到鼠标模式。

## 三、按键一览

| 按键 | 功能 |
| --- | --- |
| `R` | 重开一局 |
| `M` | 静音 / 恢复声音（也可点右下角音符） |
| `C` | 关闭 / 重新开启摄像头 |

## 四、常见问题

**Q：点击「进入」后没有弹出摄像头授权窗口？**
A：检查浏览器地址栏左侧有没有摄像头图标被划掉，点它改成「允许」。或者换 Chrome / Edge 浏览器。

**Q：手在画面里，但光标不动 / 抓不住？**
A：先看右下角小窗有没有画面和骨架。若画面是黑的，说明没拿到摄像头权限，刷新页面重新授权。若小窗正常，把手放近一点（30–60cm）、光线亮一点；握拳要握实，张开手掌要完全张开。

**Q：光标总是漂在一边？**
A：手放在画面**中央区域**最稳。手伸到画面最边缘时，光标会贴到屏幕边缘。

**Q：没有声音？**
A：必须先点「进 入」按钮才会解锁音频（浏览器策略）。按 `M` 或右下角音符可切换静音。音效是现场合成的，没有音频文件。

**Q：分错了想改答案？**
A：分错只扣时间、不跳题，同一个垃圾会飘回中间，可以再投一次。

## 五、目录说明

```
指尖分类-分享版/
├── index.html / style.css / app.js   网页本体（运行必需）
├── vendor/                           MediaPipe 手势识别库与模型（运行必需）
│   ├── mediapipe/                    wasm 与 vision_bundle
│   └── models/hand_landmarker.task   手部关键点模型
├── 启动.command                       双击启动本地服务（macOS）
├── 启动.bat                           双击启动本地服务（Windows）
└── README.md                         本文件
```

平时只需要管根目录的几个文件和启动脚本，`vendor/` 不用动。
垃圾桶、垃圾、光标、粒子全部是 canvas 现画的，`app.js` 里没有任何图片资源。

## 六、分类口径说明

按《生活垃圾分类标志》国标四分类：

| 桶 | 颜色 | 例子 |
| --- | --- | --- |
| 可回收物 | 蓝 | 报纸、饮料瓶、易拉罐、玻璃瓶、纸箱、旧书、金属勺、洗发水瓶 |
| 有害垃圾 | 红 | 废电池、过期药品、水银温度计、荧光灯管、油漆桶、指甲油、杀虫剂 |
| 厨余垃圾 | 绿 | 香蕉皮、苹果核、鸡骨头、菜叶、剩饭、蛋壳、西瓜皮、鱼骨、过期面包 |
| 其他垃圾 | 灰 | 烟头、用过的纸巾、旧牙刷、竹签、旧海绵、创可贴、破碗碟 |

具体到各城市略有差异，本游戏以最常见的口径为准。
